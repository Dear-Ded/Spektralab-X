## 当前行为

- 纸盒改为分型号的 Canvas 绘制：66×88 dp 正面、6 dp 侧棱，折痕、扣槽、纸纹、局部 UV、ISO/DIN、工艺框线和条码 / DX。Portra、Ektar、Tri-X、Velvia、Provia、800T 与 HP5 有各自版式。推片仍印原片标称感光度，电影原卷不虚构 135-36 包装规格。
- 根据用户最新比例反馈，暗盒由 20×54 dp 调整为 26×46 dp，加入黑色金属肩部和卷边，中段为印刷标签，侧边为植绒口。14 dp 斜切片头使用分工艺片基色和透明矩形齿孔。120 dp 卡片保留完整胶片名、选择语义和实际照片缩略图。
- 中性面板、.75 dp 边缘和稀疏琥珀激活提示；共享按压 .96 / spring .65/500；暗盒抽出 spring .68/420；显影 420 ms，面板 220 ms，帘幕 140 ms。选择可打断，减少动态效果直接终态。普通参数拖动不等待显影。
- 精密刻度保留直接输入与 0.01 EV 输入步进；刻距 8 dp，零位 ±.03，边界最大 12 dp 阻尼回弹，读数 4 dp / 120 ms。曲线、四区色轮与数值入口保留。一键重置和四种 TIFF 色彩空间确认使用 900 ms 蓄力，提前松手取消。
- 触觉集中至 SpektraHapticEngine：16 ms 全局最小间隔，系统与应用总开关、前台门控、逐项能力查询。API31+ 支持时组合；API29/30 采用预定义回退。主观手感仍需人实际感受。
- 五类取景器默认关闭，按真实 photoRect 绘制；仅显示真实 EXIF，缺失 --。在比较、缩放、蒙版、构图和沉浸等状态隐藏，不进入历史或导出。极光只在开屏与无照片状态，普通忙碌和导入使用中性 WorkLine。
- 中文默认、English 切换与持久化保留。沿用 Inter / Noto Sans SC / JetBrains Mono，实时数字 tnum，标签 / 标题按最新规范。开屏按可见帧钟计时，至少停留 1500 ms，再正常淡出 420 ms；保留跳过、关闭和系统禁用动画路径。
- 87 套内置风格先恢复完整物理基线，再执行各自原配方；新 CUBE 原文不超过 12 MiB 时由 SPK4 保留原始 1D / 定义域 / 3D 链。大文件有限网格回退会提示，独立导入上限仍为 64 MiB。这一轮 UI 不改变 Vulkan、RAW 默认开发、胶片 / 相纸物理数据或导出计算。
