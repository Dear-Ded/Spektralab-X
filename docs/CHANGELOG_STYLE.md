# 更新说明怎么写 / How release notes are written

更新说明是写给用户看的，不是工单清单。画风参考 B 站、小红书、酷安上开发者亲自下场写的更新日志：一个有点话痨、爱玩梗、敢自嘲的开发者，在暗房门口跟你唠这次又折腾了啥。

`CHANGELOG.md` 里每个版本的那一节会原样成为 GitHub Releases 页面的正文（`scripts/release-notes.sh`），所以写在这里就是写给所有下载的人。

## 语气

- **短句，节奏快，口语。** 一句话说一件事，能断句就断句。读起来像聊天，不像公文。
- **有网感。** 可以用括号吐槽（“（对，之前确实没有）”）、自问自答（“颜色准了吗？准了。”）、适度的网络流行语，具体用哪些见下面的梗库。
- **灵动、有梗、敢自嘲。** 可以拟人（“滑杆终于学会了听话”）、夸张、吐槽自己（“上一版那条滑杆，属于是摆设界的天花板”）。
- **抽象一点没关系，但要让人一眼看懂。** 每个梗后面跟着它到底改了什么，玩梗不能把事实玩丢。
- **贴着胶片和暗房玩梗。** 这是我们自己的梗库，比通用热梗更有辨识度，也不容易过时。
- **小标题也可以搞怪**，但要能看出这一节讲什么。
- **表情符号克制使用**，一节最多一两个，起点睛作用，不刷屏。

## 省流

每个版本的第一行是一句**省流**：一句话说清这一版最重要的两三件事，给只看一眼的人。

```
**省流：** 颜色和桌面版对上了，多了调整页和 30 款一键风格，保存按钮回来了。未大规模真机验证，需要社区反馈，慎冲。
```

- 必须在开场白之前，紧跟版本标题。
- 一句话，不超过 60 个字。
- 未大规模真机验证的版本，省流里也要带上这件事（写作“未大规模真机验证，需要社区反馈”），不能只在后面写。

## 梗库

**推荐用**

| 类型 | 例子 |
|---|---|
| 胶片和暗房 | 显影、定影、安全灯、齿孔、过期胶卷、冲扫店老板、“还在暗房里”、“这卷还没冲完”、漏光、跳片、慎冲 |
| 开发者自嘲 | 狠狠修了、破防了、这波是我的锅、属于是……、终于不用……了、你的反馈我都看到了、懂的都懂（后面必须说清楚是什么） |
| 节奏 | 省流：、问就是……、一句话：、划重点、先说结论 |
| 括号吐槽 | （对，之前确实没有）、（别问，问就是改了三遍） |

**不要用**

- 会过时的热梗：当月爆火的段子、综艺台词、某条视频的梗。一年后再看还懂的才写。
- 地域、性别、外貌、职业相关的梗，低俗梗，政治梗。
- 阴阳怪气：不嘲讽用户（“有些用户不看说明就……”），不阴阳别的项目，不调侃上游作者。
- 称呼：“家人们”“宝子们”“老铁们”“亲”。
- 营销腔：“重磅”“全新升级”“极致体验”“颠覆”“史诗级”“炸裂”。
- 刷屏的表情符号和颜文字。

## 底线（再怎么搞怪也不碰）

1. **事实不变形。** 数字、默认值、兼容性、没做完的事，一个字都不夸大，一个都不藏。梗是包装，不是遮羞布。
2. **坦白区必须有。** “还没冲洗完的”单独一节，照样可以写得有趣，但要写清楚，不能比技术细节区写得更含糊。未大规模真机验证，就明说，而且加粗。
3. **不嘲讽用户，不阴阳别的项目。** 自嘲随便，调侃上游作者不行，感谢要真诚。
4. **技术细节区不玩梗**，保持准确、可查，给想深究的人看。

## 结构（可以改名、可以加戏，但顺序大体保持）

```
## 版本号 · 日期

**省流：** 一句话总结。

> 开场白：一两句，这一版是什么心情、什么来历。

### 头条（一到两件最重要的事，讲透）
### 新玩具（新功能）
### 顺手了 / 修好了
### 还没冲洗完的（已知问题、未验证）
收尾（感谢 + 欢迎来提 Issue）

<details><summary>技术细节（硬核区，可跳过）</summary> 精确、无梗的改动清单 </details>
```

版本标题保持 `## x.y.z-alpha · 日期`，小标题用 `###`：`scripts/release-notes.sh` 按 `## 版本号` 截取，到下一个 `##` 为止，正文里不能出现 `##` 标题。没有内容的小节删掉，不要硬凑。

## 商店短说明

`fastlane/metadata/android/*/changelogs/<versionCode>.txt` 有 500 字符上限。用省流那句话开头，再补一两句同样画风的话，挑最重要的说，不列清单。未验证的声明照样要写。

## 英文

英文版用英文互联网的语气重写：像 indie 开发者的 dev changelog，轻松、自嘲、有点碎嘴（“we fixed it, for real this time”“yes, there's finally a Save button”）。不逐字翻译中文梗，换成英文读者能懂的说法；省流对应 **TL;DR**。底线和中文一样。
