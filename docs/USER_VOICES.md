# 用户声音：同类项目的口碑、吐槽与愿望

2026-11-03 调研。来源两路：国内（App Store 中国区评论、B 站和淘宝搜索结果、linux.do 摘要）和开源社区（GitHub issue、pixls 论坛、XDA、dpreview）。小红书、抖音、酷安、知乎、贴吧、Reddit 的原帖被拦截没有读到，所以国内样本偏小，结论只作方向参考。

标记：**[多]** 多个来源或多个项目反复出现；**[个]** 个别用户或单一来源。

## 2. 优点：我们可以吸收的

- **一键直出、"清透"的胶片感** [多]：一键风格（87 款）就是这个定位。
- **灰尘、颗粒、漏光可以单独调** [个，被点名夸]：效果页已有颗粒、光晕、眩光；漏光在片边里，灰尘还没有，排进效果扩充。
- **光谱模拟的质感** [多]：pixls 用户拿真实扫描对比后说"极其接近"。宣传用同一张照片在不同胶片下的对比图，不堆术语。
- **讲清楚收费的反而被夸** [个]：Fimo"付费说明非常到位"。我们讲清楚"永久免费"和资金来源（开发者寄语已写）。
- **作者坦诚回复** [多]：issue 里"未复现，不敢说已修"一类的回复受好评。更新说明的"还没冲洗完的"一节就是这个。
- **徕卡一瞬的"内置调色盘"** [个]：对应我们的二维调色盘，做成拖拽面板，不做成一排滑杆。

## 4. 宣传口径

- 第一句写"免费、无广告、无内购、不联网"，再写"开源"。普通用户先在意前者。
- "光谱模拟"用对比图讲，不用术语。
- 突出"小米 10–18 全系可用"。
