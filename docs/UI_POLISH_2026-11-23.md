# UI polish, 2026-11-23 (branch `ui-polish`)

Built on codex's `ui-motion-p0`, merged with `main` (Robolectric CI fix). The design was settled
first as a 1:1 web preview, `preview/ui-polish.html` (serve `preview/` over http; `?step` gives a
manual clock, `?slow=8` slow motion). The app now follows it. Nothing is on `main` yet.

## Rules the owner set (keep them)

1. No decoration controls. An option exists only if a real user has a reason to use it: no
   "replay intro", no intro on/off switch (the intro follows the system animation setting), no
   "show the guide again", no first-run guide at all.
2. Text on screen is a control's name, a value, or a state/error. Gesture hints, slogans,
   bracketed notes and counts are cut; if a page needs them to be understood, change the layout.
   Removed strings stay in TalkBack descriptions.
3. Targets are for thumbs: at least 48 dp, values readable at a glance. Nothing a user must aim at.
4. Camera-like where it touches the camera: dials, film, cassettes, darkroom steps, sounds.
5. Do not break anything: every export and edit of before is still reachable.

## What changed, by file

| Area | Files | Notes |
|---|---|---|
| Feedback | `Feedback.kt` (new), `Theme.kt` `View.tick`, `Interactions.kt` `View.haptic` | One entry point, `Feedback.play(view, Cue.X)`. Cues are camera actions (Detent, Zero, Limit, Ratchet, Shutter, Agitate, Saved, Rewind, Load…). Small cues use system touch effects; mechanical ones are composed vibrations on API 31+. Sounds only for shutter / advance / tank / save / rewind / load, on media volume (codex, alpha v0.3.01), setting 相机声音 (`CAMERA_SOUND`). Each cue is logged (logcat tag `Feedback`, `Feedback.recent()`). `VIBRATE` permission added. |
| Sounds | `res/raw/snd_*.ogg`, `tools/sound/cut_sounds.py` | Real film-camera recordings, CC0 1.0 from Freesound (sources and authors in the script and NOTICE): Leica M10 shutter, Canon A-1 advance stroke and its first ratchet tooth (counter), liquid swung in a bottle (tank), a 35 mm canister cap (saved), a Spotmatic back latching (load), a Fuji GW670 rewind. Each is one event, filtered (rumble, hiss, the 4 kHz small-mic edge), gated, given a 120 ms hand room and levelled (shutter loudest, counter a whisper). Ringing parts that read as a "ding" were rejected (tonality checked). `--fetch SRC` downloads the sources; the output is reproducible. |
