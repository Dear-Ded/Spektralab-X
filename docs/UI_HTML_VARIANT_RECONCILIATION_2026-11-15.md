### 3.2 可保留的最小取景框

- 默认“辅助线：无”。可选“边界角标”“三分网格”即可，不建立八套厂商模拟器；若主线程本轮只做拨盘，可先不加新取景框。
- 外侧短角标只在实际照片矩形附近有空白时画；长8..12dp、线宽1dp、白/灰低强度，不带发光。没有空白就隐藏外角，不能反向缩小照片腾位。网格为可选功能线，不常驻调色状态。
- 辅助线不接收点击/拖动、不进入导出Bitmap、不进入直方图、不写Edit历史；开关为独立显示偏好，且不改变照片几何。不能伪造圆心合焦、实时曝光或“完成”状态。
- 比较、1:1细节、裁剪操作、蒙版编辑、沉浸模式和连续调色期间，默认隐藏装饰；裁剪/蒙版需要的功能手柄优先。系统关闭动画时直接显示/隐藏，不缩放、扫光或假快门。
- 分辨率和真实EXIF放在画布外HUD/信息入口，不用取景器包围它们。未知参数留空；Exposure补偿是当前编辑值，要明确区别于拍摄时快门/ISO。

## 4. 0.200-alpha-1 本轮最小取景框方案

用户最新说明：主线程已设置 VERSION=0.200-alpha-1、versionCode=129，手机已拔出。本报告不修改版本文件、不宣称确认构建结果，也不再安排连接设备操作。

**本轮建议只做以下五项，三分网格和厂商主题均不列入必要范围：**

1. 保留现有中性照片舞台和全图 Fit。工具菜单新增可选“边界角标”，默认关闭；没有照片时不提供可用状态。若主线程需要更小改动，本轮可只保留中性舞台，角标延后，不影响发布。
2. 开启后只画四个中性短L角，不画完整封闭框、圆心、文字或测光刻度。长10dp（允许8..12dp），线宽1dp，取主题中性色约0.28 alpha；不使用琥珀/红/绿，不发光、不循环动画。
3. 边界来自**真正照片矩形**：复用 `FrameGeometry.photoRect()`（K/FrameGeometry.kt:20）及 frame.layout，不以整块舞台或固定400x300 SVG为边界。有纸框时矩形指向纸框内部照片，不把Logo区当成拍摄区域。角标画在矩形外2..4dp的空白；空白不足则隐藏对应角，不缩图让位，不盖住照片像素。
4. 初版仅在 Fit（scale=1、offset=0）、chrome显示、无比较/蒙版编辑/细节查看/阻塞打开/连续调节时显示；进入zoom/pan后直接隐藏，回Fit再恢复。这样本轮不必制造第二套变换跟随器，也不会产生“缩放后框还留在原地”的假边界。只绘制、不注册pointerInput，完全不改Edit、history、mask和导出。
5. 开关为显示偏好，不复用frame.brand。以48dp可触达菜单行操作，语义为“边界角标，开启/关闭，仅辅助显示”；无障碍树不包含四个角的装饰节点。系统关闭动画时直接切换。本轮不另外增加设置分组或新的常驻工具条。

这一方案的界面名称应为“边界角标 / Boundary guides”，不用“相机取景器 / Live viewfinder”。前者描述真实用途，后者容易暗示应用具有实时相机输入、AF和测光能力。即使名称最终保留“取景框”，说明也应明确“仅辅助显示，不改变裁剪，不导出”。

**层级边界：** 中性Viewport负责背景和边界裁切；图像层维持当前FramedImage+MaskOverlay及共同缩放；角标为无交互显示层；HUD/直方图开关为屏幕层，不能继承照片zoom；对话框与detail覆盖其上。新角标只在Fit显示，因此无需把屏幕HUD放进graphicsLayer，也无需改蒙版坐标。若以后支持缩放时网格，必须共同使用同一图像变换矩阵及photoRect，不允许分别估算。

**本轮明确不做：** 厂商八套HUD、AF框/测距圆、拍摄中曝光表、SNAP距离、35mm AUTHENTIC、胶片盒再一排、快门黑屏、滤色显影、任意crop拖拽、带取景框导出、新HDR开关或假遥测。已有真实crop/zoom/compare/1:1/histogram/源尺寸全部继续保留。

## 7. 小屏英文与无障碍保留条件

- HTML大量9..11px文字、28px HSL点和仅title提示不作为Android尺寸。必要文字至少12sp，单位/读数允许增高；48dp操作区不因屏幕变窄而缩小。English导航长标签可横滚或进明确工具列表，当前项保持可见，不通过header overflow-hidden裁掉动作。
- 320dp和fontScale1.3/2.0下，HUD先收纳次要动作，不能缩照片比例解决文字溢出；重要对比/适应/保存/构图仍可达。所有text相关高度是min，不是强制单行固定高。
- 辅助框无可访问节点；其开关有label、checked/stateDescription和Role。比较有“原图参考/编辑后”状态和可见退出，提供等效无障碍动作，不要求用户只能长按；Fit/1:1/直方图有完整按钮名称，1:1禁用/加载可读。
- 参数有真实范围、当前值、单位、reset动作和输入数值途径；保留现有setProgress、customActions，不用HTML的裸Canvas替换（K/Sliders.kt:161；K/ColorWheel.kt:132）。新角标不抢TalkBack焦点，也不增加四个无意义焦点。
- 颜色不作为唯一选中/禁用信号；仅在功能图面中保留HSL/色轮语义色。直方图开关默认收起，展开时不要盖蒙版控制点；动态更新不逐帧播报，导出只按真实阶段/结束播报。
- 系统关闭动画时，取景框、显影、扫描、包装、工作区转场均应静止/直切；仅冻结Aura不够。关闭装饰必须仍可使用全部照片功能。
