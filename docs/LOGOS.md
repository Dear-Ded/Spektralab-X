# 品牌 logo 来源记录

边框和参数水印上的品牌 logo 放在 `app/src/main/assets/logos/`，每个品牌两个文件：`logo_<id>_mono.xml`（单色，绘制时按纸色切黑 / 白墨色）和 `logo_<id>_color.xml`（彩色，只用于浅色纸）。授权说明见同目录的 `LICENSE-LOGOS.md`。

用户已决定直接内置 logo（2026-11-03），风控做法：

1. 只用版权状态有据可查的来源：Simple Icons（仓库整体 CC0 1.0）和 Wikimedia Commons 上标为 Public domain / PD-textlogo 的 SVG。没有干净来源的品牌，用 Noto Sans（SIL OFL 1.1）排印纯文字字标，不模仿品牌专有字体。
2. 版权上属于公有领域不代表商标可以随便用。logo 单独放一个目录，附 `LICENSE-LOGOS.md`；NOTICE、README 的商标一节说明不属于 GPL-3.0、无隶属或背书关系。
3. 预设名称不带品牌（"白条参数（品牌 logo）"，不叫"徕卡水印"）。
4. 权利人提出异议就删除对应文件，并在下表标"已移除"。删除后该品牌自动退回文字字标，旧存档不受影响。

## 联名标识

Xiaomi × Leica、vivo × ZEISS、OPPO × Hasselblad 没有单独的联名图形文件，绘制时把两个品牌各自的 logo 并排，中间用细竖线隔开。联名只能在边框面板里手动选，EXIF 自动识别不会给出联名（手机写入的 Make 只有手机厂商）。

## 转换方法

源 SVG 不进仓库。转换脚本在开发机 `tools/work/logos/scripts/convert.py`（不进仓库），流程：

1. svgelements 读 SVG，按绘制顺序展开所有图形，套用变换。
2. skia-pathops 做"画家算法"展平：后画的形状从先画的形状里挖掉；白色或接近白色的形状变成镂空，让纸色透出来。
3. 单色版取全部非白色形状的并集；彩色版每种颜色一条路径（亮度高于 0.72 的颜色并入近黑 `#1A1A1A`，保证在白纸上看得见）。
4. Simple Icons 图标是单色字形，彩色版用其 `hex` 品牌色。
5. 输出 VectorDrawable XML，视口高度 100，路径数据只用绝对坐标 `M L C Q Z`，应用内用自带的小解析器转成 `android.graphics.Path`，在导出画布上按目标分辨率直接矢量绘制（不经过 VectorDrawable 的 2048 px 缓存位图，大图不发糊）。

文字字标用 fontTools 把 Noto Sans Bold 字形轮廓转成路径，同样输出为 VectorDrawable。

验证：把每个 XML 再转回 SVG 用 resvg 渲染，彩色 / 白底单色 / 黑底单色三栏与源图逐个目视对照（33 个品牌全部一致）。
