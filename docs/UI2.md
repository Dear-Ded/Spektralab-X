> 状态：**v2.0-a，第 1–4 步已实现（2026-11-04），待逐页检查与真机验证。** 取代 [UI.md](UI.md) 的第 0–2 节；UI.md 的附录（组件、沉浸式、观片台、边框）在不冲突的地方继续有效。改界面先改这里。

## 0. 用户反馈，逐条对应

| 反馈 | 这一版怎么改 | 小节 |
|---|---|---|
| 交互费劲，选项选中了没有、选的是哪个看不清 | 选中靠反色实心胶囊 + 形状变化，不靠颜色 | 1.2 |
| 排版逻辑乱，东西找不到、不知道怎么用 | 两条路线 + 按冲洗工序排；每个控件一句说明；最多两层 | 2 |
| 下方操作区太满，选起来费劲 | 一次只显示一个主控件；常用项外露，其余收进“更多参数”；点击区 ≥ 48 dp | 2.3 |
| 不要黑底橙色 | 中性灰 + 黑白透明度叠层，没有彩色强调色 | 1.1 |
| 曲线图上滑不动页面 | 二维控件只在按住控制点时接管手指，上下滑交给页面（33d7bcc 已修） | 3.3 |
| 一键重置要二次确认 | 顶栏“重置全部”+ 确认框，可撤销（d3fdd15 已加） | 2.5 |
| 专业玩家要极致、小白要能尝鲜 | 同一套参数分三层深度，停在哪层都能出片 | 0.1 |
| 沉浸感、跟手、丝滑 | 拖动 1:1，松手弹簧；拖滑杆时面板淡到只剩数值；照片尽量满屏 | 3 |

### 0.1 三层深度

| 层 | 给谁 | 看到什么 |
|---|---|---|
| 第 0 层：一键风格 | 只想出片的手机用户 | 热门风格卡片，点一下出片，再点一下调强度。界面上没有专业名词 |
| 第 1 层：工序常用项 | 想多玩一点的人 | 冲洗每一步只露 2–3 个常用控件，每个配一句说明 |
| 第 2 层：完整参数 | 胶片玩家 | 每一步展开“更多参数”，引擎的全部参数都在，和桌面版一样多 |

- 三层是同一张照片、同一套参数：套了风格可以接着进工序细调。
- 默认停在第 0 层。设置里有“默认展开全部参数”，给玩家用。
- 每一层、每一个分类都能单独重置。

## 1. 视觉

### 1.1 颜色

不再有琥珀色。界面全部是中性灰，层级靠明度和白色透明度叠层，没有色相，所以面板永远不会把照片四周染色。

| 名称 | 值 | 用途 |
|---|---|---|
| Ground | `#0E0E10` | 应用背景、底部面板底色 |
| Surround | `#1E1E1E`（设置里可改 18% 灰 `#2E2E2E` / 黑 / 白） | 只用于照片四周 |
| Layer1 | 白 6% | 卡片、未选中的胶囊 |
| Layer2 | 白 10% | 按下、悬浮层 |
| Layer3 | 白 14% | 菜单、数值气泡 |
| Hairline | 白 8% / 12% | 分隔线、描边 |
| Text | 白 92% / 64% / 40% | 主文字 / 说明 / 禁用 |
| Selected | `#F2F2F2` 底 + `#111113` 字 | 选中项：反色实心胶囊 |
| Primary | `#F2F2F2` 底 + `#111113` 字，全圆角，比其他按钮大一号 | 保存、导出这类主操作 |
| Destructive | `#FF6B5E` | 只用于“重置”“删除”的确认按钮文字 |
| Glow | Gemini 现行配色：蓝 `#3186FF` 为主（约一半），浅蓝 `#749BFF`、红 `#FC413D`、黄 `#FBBC04`、绿 `#00B95C`、青 `#24A2CA` 只在下沿小块流过，没有紫色（Aura.kt `AuraColors`；ui-motion_gemini_glow.md） | 只用于“正在处理”：启动、等待、空白页，以及工具栏里的处理指示条。不出现在照片边上 |

“偏离默认值”的数值用 Text 92% + 一个小圆点标记，不再用橙色。

### 1.2 选中状态

一眼看出“选的是哪个”，三条同时用：

1. **反色**：未选中是透明或 Layer1 上的浅色字，选中是 Selected 实心底深色字。
2. **形状**：未选中 12 dp 圆角，选中变成全圆角胶囊（graphics-shapes 变形，effects 弹簧）。
3. **字重**：选中项的文字从 Regular 变 Medium，字号不变。

缩略图卡片（风格、胶卷、边框）选中时加 2 dp 白色内描边，名称变成反色胶囊。

### 1.3 字体、形状、间距

- 字体用系统字体（HyperOS 上是 MiSans），不在线下载、不打包额外字体。数字用等宽数字 `tnum`。字号表沿用 UI.md 第 1 节，中文不小于 12 sp，`zh-CN` 字形。
- 圆角：照片 0；缩略图 12；卡片 16；面板顶部 28；按钮、胶囊、工具栏全圆角。
- 点击区不小于 48 × 48 dp；同一行的可点项之间至少 8 dp。

## 2. 信息架构

### 2.1 编辑器布局

```
┌──────────────────────────────┐
│ ‹  照片名        ↶ ↷ ⟲  ⋯    │  顶栏 56 dp，半透明，轻点照片隐藏
│                              │
│           照片（尽量满屏）       │  Surround 中性灰
│                              │
│   [对比]               [1:1]  │  照片上两个可见按钮
├──────────────────────────────┤
│  面板（按需展开，高度跟内容）       │  一次只显示一个主控件
├──────────────────────────────┤
│ ( 风格  冲洗  调整  边框  构图 ) [保存] │  底部浮动胶囊工具栏 64 dp
└──────────────────────────────┘
```

- 底部是一条浮动胶囊工具栏，五个入口 + 右侧一个“保存”主按钮。保存从顶栏移到拇指够得着的地方。
- 点一个入口，面板从工具栏上方升起；再点一次同一个入口或下滑面板，面板收起，照片回到最大。
- 面板默认半高（约屏幕 36%），可上拉到 3/4 看完整参数；高度跟内容走，不留空白。
- 顶栏只留：返回/打开、撤销、重做、重置全部、⋯（观片台、正在处理、检查更新、设置）。

### 2.2 五个入口

| 入口 | 面板第一层 | 第二层 |
|---|---|---|
| **风格**（第 0 层） | 分组胶囊：热门、胶卷、相机、手机、电影、黑白、摄影师、我导入的；右侧搜索 | 风格卡片（用你的照片做缩略图）。点一下出片，再点一下出强度滑杆 |
| **冲洗**（第 1–2 层） | 工序条：① 胶卷 ② 相纸 ③ 曝光与放大 ④ 胶片效果，可点可滑，底部“下一步” | 见 2.3 |
| **调整** | 分段：光线、色彩、曲线、调色盘、细节 | 每段的控件；“更多参数”展开其余 |
| **边框** | 分组胶囊：无、简洁留白、胶片片边、拍立得、品牌数据条、只加齿孔 | 边框卡片（你的照片做缩略图）；选中后下方出现这一款的设置：logo、日期、拍摄参数、齿孔样式 |
| **构图** | 比例胶囊：原始、1:1、3:2、2:3、4:3、3:4、16:9、XPan | 旋转、翻转、拉直 |

每个入口、每个分组在改过之后显示一个小圆点；面板右上角有“重置这一项”。

### 2.3 冲洗工序

按真实暗房的顺序，每一步只放这一步的东西：

| 步骤 | 常用项（外露） | 更多参数（展开） |
|---|---|---|
| ① 胶卷 | 胶卷卡片（彩负、反转、电影、黑白四组），每张写片名和一句特点 | 画幅、推拉冲（曝光补偿） |
| ② 相纸 | 相纸卡片，默认是胶卷推荐的那一张，标“推荐” | 黑白相纸色调 |
| ③ 曝光与放大 | 拍摄曝光、放大曝光、自动曝光开关 | 黄 / 品红滤镜、RAW 白平衡、测光方式 |
| ④ 胶片效果 | 颗粒强度、光晕、眩光 | 颗粒尺寸与分层、光晕扩散、成色剂、扫描锐化 |

- 工序条上已经改过的步骤显示圆点；当前步骤是反色胶囊。
- 每一步顶部一句话说明这一步在暗房里是做什么的（例如“相纸决定反差和色调，就像放大时换一盒相纸”）。

### 2.4 一次只有一个主控件

- 面板里同一时间只有一组主控件：一排卡片，或 2–3 根滑杆，或一个曲线图/调色盘。别的收进“更多参数”或下一步。
- 风格条、胶片条、预设不再挤在同一页：风格（含预设、导入的风格）只在“风格”，胶卷只在“冲洗 ①”。
- 片边、日期后背、齿孔、logo 全部只在“边框”，不再分散在构图页。

### 2.5 重置

- 顶栏“重置全部”：确认框写明会还原什么，确认按钮用 Destructive 色，一步可撤销（已实现）。
- 每个入口和分组：“重置这一项”，不需要确认（单项、可撤销）。
- 滑杆双击数值归零，保留。

### 2.6 说明文字

- 每个分类一句说明，每个参数在名字下面一行小字说明效果，用效果说话，不用术语。
- 第一次进入每个入口，首次引导指向真实控件（Coach.kt），一个入口一条，最多五条。

## 3. 交互与动效

> 调研：`ui2_research_benchmarks.md`、`ui2_tech.md`，以及 2026-11-05 补充调研 `ui-motion-research.md`（M3 Expressive 源码、预测性返回官方指引、HapticFeedbackConstants）。Gemini、Google Photos、Lightroom 都没有公开动效数值，下面凡是写“推断”的，是按它们的行为和官方指引定的，等真机校对。
> 组件在 `Interactions.kt`（按压、选中、震动、吸附、预测性返回）和 `Transitions.kt`（共享元素）。其他文件直接调用，不要自己再写一套。

### 3.1 跟手

- 拖动时数值、位置 1:1 跟手指，不加动画；松手后带手指速度进入弹簧（`Animatable.animateTo(..., initialVelocity = v)`）。
- 拖动中读的状态只在 layout / draw 阶段读：`Modifier.offset { }`、`graphicsLayer { }`、`drawBehind { }`。不写 `Modifier.height(x.dp)` 这类在组合阶段读的形式。
- 越过阈值才生效的判断（面板该吸到哪档、滑过一格）用 `derivedStateOf`，只在结果变化时重组一次。
- 编辑器和观片台申请高刷：`Modifier.preferredFrameRate(FrameRateCategory.High)`，只在 API 35+ 生效；Compose 在图层动画时本来也会投 High 票。

### 3.2 弹簧（照搬 M3 Expressive 数值，手写，不升级 Material3）

| 用途 | 阻尼 / 刚度 | `Motion.` |
|---|---|---|
| 小元素：胶囊、开关、按下、指示器 | 0.6 / 800 | `fastSpatial` |
| 面板、卡片、默认位移 | 0.8 / 380 | `defaultSpatial` |
| 全屏转场、共享元素 | 0.8 / 200 | `slowSpatial` |
| 颜色、透明度（快 / 默认 / 慢） | 1.0 / 3800、1600、800 | `fastEffects` / `defaultEffects` / `slowEffects` |

- 规则（M3 `MotionScheme` 源码原话）：改形状、尺寸、位置的用 spatial；颜色和透明度用 effects，effects 不回弹。
- 按尺寸选快慢（MDC Motion 文档）：小控件 fast，盖住一部分屏幕的（底部面板）default，全屏 slow。
- 没有时长和缓动曲线：弹簧会被打断后从当前速度接着走，适合手势随时反悔。

### 3.3 手势规则

- 二维控件（曲线、调色盘）只在按住控制点时接管手指；从空白处上下滑交给页面滚动。
- 滑杆只接管横向拖动；竖向一律让给页面。
- 每个手势都有可见按钮：长按对比 ↔ “对比”按钮；双击缩放 ↔ “1:1”按钮；滑杆双击归零 ↔ “重置这一项”。

### 3.4 沉浸

- 轻点照片：顶栏、工具栏、面板一起淡出，系统栏隐藏（已有）。
- 拖滑杆时：面板和工具栏淡到 0，只留一个数值气泡在手指上方；松手后回来。
- 照片永远不移动、不缩放来给面板让位；面板压在照片下沿之上时，照片区按剩余高度居中，切换入口时照片尺寸不变。
- 毛玻璃：默认关。设置里“界面毛玻璃”开关，只在 Android 12+ 可开，模糊的是照片的缩小副本，不在照片正下方。

### 3.5 震动

统一调用 `Interactions.kt` 的 `View.haptic(HapticEvent)`；API 30 / 34 的新常量都有回退，最低 API 29。`performHapticFeedback` 遵守系统“触摸反馈”开关，不需要 VIBRATE 权限；官方不建议用 `createOneShot` 这类马达直驱。

| 事件 | `HapticEvent` | 常量 | 回退 |
|---|---|---|---|
| 滑杆经过 / 吸附默认值 | `Tick` | CLOCK_TICK | — |
| 滑杆到头 | `Edge` | GESTURE_THRESHOLD_ACTIVATE (34) | CLOCK_TICK |
| 档位拨盘每一档、面板吸附到一档、片条过一格、网格换列数 | `Segment` | SEGMENT_TICK (34) | CLOCK_TICK |
| 重置、导出完成、选中照片 | `Confirm` | CONFIRM (30) | VIRTUAL_KEY |
| 套用风格、工序“下一步” | `Click` | CONTEXT_CLICK | — |
| 打开强度面板、开始拖动面板 | `GestureStart` | GESTURE_START (30) | CONTEXT_CLICK |
| 拖动面板松手 | `GestureEnd` | GESTURE_END (30) | — |
| 长按对比、长按多选 | `LongPress` | LONG_PRESS | — |
| 开关打开 / 关闭 | `ToggleOn` / `ToggleOff` | TOGGLE_ON / OFF (34) | CLOCK_TICK |
| 出错、淘汰照片 | `Reject` | REJECT (30) | LONG_PRESS |

拖动过程中不连续震动，滑过胶片条时也不逐个震动；只在跨过档位的那一下震一次。

### 3.6 按压与选中

| 状态 | 视觉 | 动画 |
|---|---|---|
| 按下 | 缩到 0.96 | `fastSpatial`，松手回弹略过 1.0 |
| 选中 | 填充反色（近白底深色字）+ 圆角从 12 dp 变到全圆 + 字重 Medium | 圆角 `fastSpatial`，颜色 `defaultEffects` |
| 不可用 | 透明度 0.6，不缩放 | — |

- M3 Expressive 自己的按钮按下是“形状变方”（全圆 → 8 dp），不缩放；ToggleButton 选中时变形用 FastSpatial。我们两样都要：按下缩放给手指确认，选中变形告诉眼睛状态。数值见 `ui-motion-research.md` 第 1 节。
- 连在一起的按钮组（分段按钮）：间隙 2 dp，内侧圆角 8 dp，选中的那段变成全圆。
- 实现：`Modifier.pressScale(interactionSource)`、`rememberSelectionStyle(selected)`、`Modifier.morphingPill(...)`，都在 `Interactions.kt`。

### 3.7 转场

| 从 → 到 | 怎么走 | 弹簧 |
|---|---|---|
| 观片台网格缩略图 → 单张查看 | 共享元素：缩略图的位置和大小长到全屏，背景从 0 淡到不透明 | 位置 `slowSpatial`（推断：Google Photos 的同类动作） |
| 单张查看 → 编辑器 | 共享元素：同一张照片原位不动，周围的面板从下往上进来 | `defaultSpatial` |
| 风格 / 胶卷卡片 → 强度面板 | 卡片的圆角容器长成面板（sharedBounds），文字淡入 | `defaultSpatial` |
| 编辑器五个入口之间 | 方向性滑动：往右的入口从右进，往左的从左进，位移 1/8 宽，淡入淡出 | 位移 `defaultSpatial`，淡入 `defaultEffects`，淡出 `fastEffects` |
| 面板三档高度 | 拖动 1:1；松手按位置和速度吸到最近一档，快速甩动多走一档 | `defaultSpatial`，带松手速度 |
| “更多参数”展开收起 | 高度展开 + 内容淡入；箭头转 180° | 高度 `defaultSpatial`，淡入 `defaultEffects` |

- 照片本身不做慢动画：前后对比、换胶片后的结果、拖动中的实时渲染一律立即替换（换胶片保留现有的 `defaultEffects` 交叉淡化，不用位移）。
- 共享元素只在 `SharedTransitionLayout` 内生效；拿不到作用域时组件退回普通显示，不报错。

### 3.8 预测性返回

| 位置 | 返回手势中 | 松手提交 | 取消 |
|---|---|---|---|
| 底部面板展开 | 面板跟手往下收，最多收到少一档 | 吸到下一档 | 弹回原高度 |
| 1:1 查看 | 整屏缩到 90%，边距 8 dp，向手势反方向偏移，背景渐暗 | 收回到编辑器 | 回到 100% |
| 单张查看 → 网格 | 照片跟手缩小，松手后共享元素飞回格子 | 回网格 | 回全屏 |
| 编辑器 → 观片台 | 编辑器缩到 90% 淡出，观片台从 110% 缩回 100% 淡入（官方“fade through”） | 进观片台 | 回编辑器 |
| 观片台根部 | 不拦截，交给系统做返回桌面动画 | — | — |

- 官方指引：进度先过 `PathInterpolator(0, 0, 0, 1)`（减速）再用，不直接用原始进度；最小缩放 90%，边距 8 dp，水平偏移 `宽/20 − 8 dp`。
- 根 Activity 拦截返回会让系统“返回桌面”动画失效。所以观片台根部只在有多选时才注册返回（`BackHandler(enabled = selecting)`）；直接退到桌面交给系统。
- 返回顺序：面板展开时先收面板，再退出沉浸，再离开编辑器（见 3.3）。
- 实现：`rememberBackProgress()` + `Modifier.predictiveBackScale(...)`，`SeekableTransitionState` 驱动整屏切换（`Interactions.kt`、`LightTableNav.kt`）。

### 3.9 系统“移除动画”

- Compose 读 `ANIMATOR_DURATION_SCALE`：为 0 时所有弹簧、`animate*AsState`、`Animatable`、`Transition` 下一帧直接到终点，不用自己判断。
- 不受影响的是手势值（拖动位移、返回进度、`seekTo`），这本来就该跟手。
- 自己写的帧循环（`withFrameNanos`、Aura 的无限动画）要查 `rememberReduceMotion()`（`Interactions.kt`），为 true 时停住。
- 共享元素在移除动画下直接切换，不飞。

## 4. 逐页检查表

每个页面、每个控件都要能回答三个问题，答不上来就改：

1. 它是干什么的？（名字 + 一行说明）
2. 现在是什么状态？（选中、改过、默认）
3. 怎么操作？（可见的按钮或首次引导）

页面清单：空白页、编辑器五个入口各自的面板、顶栏菜单、设置、正在处理、导入页、1:1 查看、观片台（网格、单张、卷列表、片条、印样、风格比较、批量）。

## 5. 技术约束（ui2_tech.md）

- 留在 compose-bom 2026.01.00 / material3 1.4.0：Expressive 组件在 1.4.0 不可用，升 1.5.0-beta 要同时升 Kotlin，风险大。浮动工具栏、按钮组自己写。
- 可用：`androidx.graphics:graphics-shapes:1.1.0`（形状变形）、`SharedTransitionLayout`（卡片到大图的共享元素）、`SeekableTransitionState`、`PredictiveBackHandler`、`SegmentedButton`。
- 不用：在线下载字体、haze 2.x、RenderScript 模糊、动态取色（编辑界面里）。
- HyperOS：`isNavigationBarContrastEnforced = false`，浮动工具栏后面的导航栏保持透明。

3. **入口重排**：风格、冲洗工序、调整、边框、构图按第 2 节重排内容，补说明文字和改过标记。

5. **其他页面换装**：观片台、设置、正在处理、导入页、更新弹窗用新组件。
6. **逐页检查**：按第 4 节过一遍，修完再发布。

### 7.2 要借鉴的点（逐条，对应到我们的代码）

1. **一个面板只做一件事，留白比控件多**（VSCO、Darkroom）。面板里一屏只露一组主控件：一排卡片，或最多 3 根滑杆。其余收进“更多参数”。控件行之间 16 dp，组之间 24 dp，不用分割线。→ `EditorScreen.kt` Controls、`AdjustPanel.kt`、`Effects.kt`。
2. **面板头固定三行：标题 · 摘要、一句说明、主控件**（Lightroom 的“Style: Film-Inspired”，Silverphase 的“Portra 400”）。标题用 titleSmall 白色，右侧是当前状态摘要（`Portra 400 · Endura`、`光线 · 已改 2 项`），说明用 bodySmall 64% 白。重置放在标题行最右侧，文字按钮“重置”，没改动时隐藏。→ 新组件 `PanelHeader`（`Pill.kt`）。
3. **选中靠反色实心 + 形状，不靠描边颜色**（Lightroom 的实心方块）。我们的 `SelectPill` 已经这样做；工具栏、分段、工序条统一用它。卡片选中：2 dp 白色描边 + 2 dp 间隙 + 名称条反色 + 右上角一个对勾小圆。→ `Pill.kt` 新增 `ThumbCard`，风格、胶卷、相纸共用。
4. **缩略图卡片大、方、统一**（Lightroom 4 张一屏、醒图竖卡）。风格和胶卷卡 104 × 104 dp 方图，圆角 12，下面两行字：名称（labelLarge）+ 一行说明（labelSmall 64%）。一屏露 3.3 张，让人知道能横滑。→ `Styles.kt` StyleStrip、`EditorScreen.kt` FilmStrip。
5. **卡片条最前面放“无”**（醒图的 ⊘、上游 issue #31）。相纸条已有“直接扫描”，边框条已有“无边框”。风格条暂不加“原图”卡：现在没有“不套风格”的编辑状态，加它要改 ViewModel，不在这一轮范围内，记为待办。
6. **滑杆一行：名称左、数值右、轨道在下**（Lightroom、Darkroom）。数值用等宽数字，未改动时 40% 白，改过后 92% 白 + 前面一个小圆点；不再用主色。拇指是实心白圆，轨道 2 dp，默认值刻度保留。行高 56 dp（名称 20 + 轨道 36），满足 48 dp 点击区。→ `Sliders.kt`。
7. **开关做成整行可点**（Lightroom 设置、HyperOS）。`SwitchRow` 和 `Toggle` 合成一个 `SettingRow`：名称 + 可选的一行说明在左，开关在右，整行 56 dp 可点。开关颜色：开 = 白底黑点，关 = Layer2 底 64% 白点。→ `Pill.kt` 新增 `SettingRow`，替换 `SwitchRow`、`Toggle`。
8. **分段控件用一条轨道包住**（Hark 的套餐切换、M3 SegmentedButton）。2–4 个互斥选项（画幅、日期顺序、齿孔位置）放在一条 Layer1 轨道里，选中段是反色实心胶囊，44 dp 高。比一串散的胶囊更容易看出“这几个是一组、只能选一个”。→ `Pill.kt` 新增 `Segmented`。
9. **“更多参数”是一行，不是按钮**。左边“更多参数”，右边旋转箭头，改过时箭头前一个圆点；整行 48 dp。→ `Pill.kt` 新增 `MoreRow`，`Effects.kt` 和第 ①③ 步共用。
10. **工具栏图标下的“改过”圆点**（Lightroom 每个工具下面一个点）。五个入口哪个改过就在图标右上角画 6 dp 圆点。→ `CategoryBar.kt` 加 `edited` 参数。
11. **数值不在面板里抢眼，拖动时在手指上方**（剪映、Darkroom）。保持现在的数值气泡；拖动时面板其它行淡到 30%，只留当前滑杆。→ `Sliders.kt` 已有气泡；淡出归 ui-motion。
12. **照片四周只有中性灰**（Darkroom 推荐中灰判断色彩）。面板不用彩色、不用模糊；`Surround` 不动。

### 7.3 不学的

- VSCO 的不显示数值：胶片玩家要精确复现参数，数值必须在。
- 醒图、Lightroom 的彩色选中（绿描边、蓝方块）：违反 1.1，选中只用反色。
- Lightroom 的两层图标栏：我们五个入口已经是一层，子分类用文字分段，不再加第二排图标。
- Darkroom 的照片延伸到工具区后面：违反“照片四周保持中性灰，不能让模糊挨着照片”。
