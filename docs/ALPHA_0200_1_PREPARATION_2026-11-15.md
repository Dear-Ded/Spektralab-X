## 已在 HEAD、尚未发布的引擎修正

已完整阅读 [STYLE_ENGINE_FIDELITY_2026-11-15.md](STYLE_ENGINE_FIDELITY_2026-11-15.md) 并核对 `git show d1a0232` 摘要；提交主题为 `Preserve original LUT chains and canonical builtin style recipes`，已确认它是当前 HEAD 的祖先。这些改进此前未发布，应计入本轮，不只记录新 UI。

- **87 套内置风格恢复完整物理基线后再应用各自原配方。** 修正前序风格遗留的预闪、染料耦合、散射、底片前曲线、测光与部分扫描 / 镜头设置；内置风格分享携带完整引擎设置。87 套原有审美参数、胶片 / 相纸物理数据与默认 RAW 开发方式未改。照片的 RAW 开发、RAW 曝光、裁切、旋转和局部蒙版保留；用户文件省略可选引擎字段时仍沿用原有继承规则，不能扩大为所有导入配方均强制重置。
- **新导入 CUBE 原文不超过 12 MiB 时，保留并执行原始链。** SPK4 原子保存原文、原始色彩空间与兼容表；原生 `SourceLut` 直接执行 1D 线性插值、两套定义域、3D 四面体插值及原有色彩空间转换，分享携带原文字节。纯 ProPhoto、单位定义域、无整形且边长不超过 65 的源表保留既有直接查表路径；不称所有 CUBE 都增加了相同开销。
- **旧缓存不自动改变，旧照片不会静默换路径。** SPKL / SPK2 / SPK3 缓存继续原烘焙结果；要使用这次原始链修正，应从保留的 CUBE 原文重新导入。Hald 仍走既有烘焙路径。LUT 强度混合与 Layer 2 顺序保持。
- **大文件保留有限网格回退并提示。** 独立 CUBE 导入上限仍为 64 MiB，超过包内 12 MiB 原文上限时使用有限网格；分享携带最终 ProPhoto 表，以可往返 Float 文本保存该网格数值。导入报告说明限制；该回退仍有网格误差，不称为原始链无损，也不把原生大边长容量测试外推到任意大文件。
- **原始链更耗 CPU。** 尤其 sRGB 链还包含逐像素转移函数与矩阵；既有记录是共享云宿主机的局部 CPU 耗时，不是手机延迟、整张导出速度或手机发热 / 续航成绩。新路径的手机耗时、发热与内存待后续真机测量，本轮不转抄云端耗时作为手机性能结论。
- **目录与厂商边界不变。** 上一轮十款原创候选仍不自动纳入内置目录，不能把本轮说成新增十款内置厂商风格。厂商 profile 仍属研究、准入与适配准备，不声称新增经过实测的厂商风格或官方同色。

原记录已有的组件、往返、原生与 ARM64 证据只绑定各自测试条件；本次仅引用，不将其通过数填入 code129 的最终验证栏，也不把共享库链接等同完整 APK 安装验收。

## 角标：按实际实现记录

主线程已接入“照片边界角标”。它是可选的照片边界提示，不是相机取景框或裁剪控件。用户在更多菜单切换，偏好保存在 `preview_boundary_corners`，默认值为 `false`。

| 项目 | 当前实现 |
| --- | --- |
| 几何依据 | 按 `FrameGeometry.photoRect` 的真实照片矩形定位，包含相纸边框内的实际照片边界 |
| 尺寸与颜色 | 线长上限 10 dp，且不超过照片宽/高各自的四分之一；线宽 1 dp；中性白，38% 不透明度 |
| 绘制位置 | 贴照片边界，向内半个笔画绘制，`inset = stroke / 2f`；**没有采用外侧 2..4 dp 留白建议** |
| 可见条件 | 开关开启、Fit 状态且无平移，并显示普通界面；比较、蒙版、构图、细节、阻塞、加载/渲染或调节时隐藏，沉浸时也隐藏 |
| 数据与布局 | 只叠加绘制；开关不改变照片布局或 Edit，不缩图，不生成导出边框，不进入成片 |
| 舍弃的装饰 | 无机身壳、彩色 HUD、相机实时数据文字或伪遥测 |

内侧绘制是本轮明确采用的取舍：无边框照片在 Fit 下至少填满一个轴，若强制要求外侧余量，该轴的角标会始终看不到。当前实现以默认关闭、极短中性线和状态隐藏限制遮挡，不为装饰缩小照片。此前 [HTML 对照报告](UI_HTML_VARIANT_RECONCILIATION_2026-11-15.md) 的外侧留白属于设计建议，不能当成已实现行为。
