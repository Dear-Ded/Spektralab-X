# 独立滤镜、自定义胶卷与组合

2026-11-13，GPT（OpenAI）共创。实现于研究分支，尚未发布 APK 或真机验收。用户明确要求不改 UI，本文已按该要求修订，替代上一轮范围选择控件的操作说明。

## 用户操作

| 目标 | 操作 |
| --- | --- |
| 不使用胶卷和相纸，只加滤镜保存图片 | 冲洗里的胶卷选“无”，使用原有数字调色 / LUT，再用原有“保存”导出图片 |
| 自定义胶卷、相纸和滤镜组合 | 在原有入口选择胶卷、相纸和数字调整；胶卷、相纸各自的“无”选项继续可用 |
| 保存自己的滤镜或组合 | 我的 → 存为风格，填写名称并保存，自动记录当前选择 |
| 分享可复用效果 | 设置中的“分享当前风格”填写名称，导出当前选择的 `.spklook` |

没有新增模式、应用范围、保存范围或分享范围。风格页、导入 / 分享对话框和面板文案恢复原状，风格“无”仍清除整套风格；胶卷“无”只旁路胶卷和相纸，保留数字调色。选择内置完整风格仍使用它原有的胶卷配方；若只需要数字调色，可再把胶卷选为“无”。

这里的自定义胶卷是基于已有胶卷、相纸和物理参数保存配方。已有的完整光谱胶卷数据导入继续可用，本轮没有新增光谱曲线编辑器。每张图仍使用一个物理胶卷方案和一个数字调色层 / LUT，支持二者组合，不提供多个 LUT 顺序堆栈。内置风格提取出的数字调色部分，也不等于该风格完整的物理胶卷外观。

## 参数合同

`StyleScope` 只作为配方文件的内部合同保留：完整组合、仅数字调色、仅物理配方。导入时遵循文件本身的范围，界面不切换或提取范围。`Style.applyTo` 在文件指定仅数字调色时只更新全局 `Look`，保留物理参数和当前局部蒙版；仅物理配方保留整个当前 `Look`。现有本机保存与分享自动记录当前完整选择，包括明确的无胶卷状态。

`Edit.savedStyle` 是本机保存和分享文件共用的参数快照。`.spklook` 写出 version 2，并继续读取 version 1。新增 `scope`、胶卷 / 相纸旁路状态、完整的已开放物理细调、效果开关和记住的强度、数字灰尘 / 划痕。旧文件缺少新字段时保留原有应用方式。新应用遇到不认识的 scope 拒绝应用，避免误按完整组合覆盖设置；旧应用不能保证正确还原 v2 的新语义。

色调盘先解析成最终参数再保存，LUT 保留原表及其色彩空间。滤镜强度仅缩放数字调色及灰尘；0 强度明确回到中性。局部蒙版属于当前照片，不进入可复用风格，应用风格也保留当前蒙版。RAW 显影 / 白平衡、裁切、旋转、边框和日期不进入风格文件。

图片保存继续使用原有导出队列的 `editJson` 与独立 `lookJson`，不用把数字滤镜转换成胶卷参数。
