# 独立滤镜、自定义胶卷与组合

2026-11-13，GPT（OpenAI）共创。实现于研究分支，尚未发布 APK 或真机验收。

## 用户操作

| 目标 | 操作 |
| --- | --- |
| 不使用胶卷和相纸，只加滤镜保存图片 | 风格页点“移除胶卷”（已无胶卷时省略），选“仅滤镜”，选风格或在调整页自定义调色，再用原有“保存”导出图片 |
| 将胶卷 A 和滤镜 B 混搭 | “仅胶卷”选 A，再“仅滤镜”选 B；两个操作保留另一部分，也可以倒序 |
| 保存自己的滤镜 | 我的 → 存为风格 → 仅滤镜，填写名称并保存 |
| 保存自己的胶卷方案 | 先选胶卷、相纸并调冲印和物理效果，我的 → 存为风格 → 仅胶卷 |
| 保存整套组合 | 我的 → 存为风格 → 完整组合；会明确记住无胶卷、相纸无、直接扫描等状态 |
| 分享可复用效果 | 设置中的“分享当前风格”选择范围，导出 `.spklook` |

“完整组合”浏览方式尊重自定义文件原本保存的范围。因此点一个保存为仅滤镜的条目，仍然只换滤镜。“无”卡则遵循当前应用范围：清除全部风格、清除滤镜、或移除胶卷。

这里的自定义胶卷是基于已有胶卷、相纸和物理参数保存配方。已有的完整光谱胶卷数据导入继续可用，本轮没有新增光谱曲线编辑器。每张图仍使用一个物理胶卷方案和一个数字调色层 / LUT，支持二者组合，不提供多个 LUT 顺序堆栈。内置风格提取出的数字调色部分，也不等于该风格完整的物理胶卷外观。

## 参数合同

`StyleScope` 表达完整组合、仅滤镜、仅胶卷。`Style.applyTo` 在仅滤镜时直接更新全局 `Look`，保留胶卷、相纸、曝光、物理效果、几何、RAW 显影和当前局部蒙版；仅胶卷保留整个当前 `Look`。滤镜单独应用不要求目录中存在其示意胶卷，也沿用 `sameRenderInputAs` 的打包路径，不强迫重新冲洗。

`Edit.savedStyle` 是本机保存和分享文件共用的参数快照。`.spklook` 写出 version 2，并继续读取 version 1。新增 `scope`、胶卷 / 相纸旁路状态、完整的已开放物理细调、效果开关和记住的强度、数字灰尘 / 划痕。旧文件缺少新字段时保留原有应用方式。新应用遇到不认识的 scope 拒绝应用，避免误按完整组合覆盖设置；旧应用不能保证正确还原 v2 的新语义。

色调盘先解析成最终参数再保存，LUT 保留原表及其色彩空间。滤镜强度仅缩放数字调色及灰尘；0 强度明确回到中性。局部蒙版属于当前照片，不进入可复用风格，应用风格也保留当前蒙版。RAW 显影 / 白平衡、裁切、旋转、边框和日期不进入风格文件。

图片保存继续使用原有导出队列的 `editJson` 与独立 `lookJson`，不用把数字滤镜转换成胶卷参数。无胶卷且已调色时，面板摘要显示“无胶卷 · 已调色”。
