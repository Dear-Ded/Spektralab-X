# 错误编码表

每个导出失败或引擎异常都带 E-xxxx 编码，方便截图反馈时定位问题。

## E-1xxx：引擎与 GPU

### E-1001：引擎启动失败
**含义**：Vulkan 引擎初始化失败，通常是 GPU 驱动不兼容或设备不支持 Vulkan。

**该怎么办**：
- 检查设备是否支持 Vulkan（Settings → About → GPU）
- 尝试重启设备
- 如果是较旧机型，可能不支持本应用

### E-1002：GPU 被系统重置
**含义**：GPU 设备丢失（VkResult -4），通常是系统为了省电或散热强制重置了 GPU。

**该怎么办**：
- 等待设备降温后重试
- 调小工作尺寸（Settings → 画质与导出 → 工作尺寸）
- 关闭其他占用 GPU 的应用

### E-1003：引擎异常
**含义**：引擎处理时遇到未预期的错误。

**该怎么办**：
- 复制诊断信息（Settings → 关于与诊断 → 复制诊断信息）
- 到 GitHub Issues 提交错误报告，附上诊断信息和出错时的操作

## E-2xxx：内存与资源

### E-2001：内存不足
**含义**：系统内存不足，无法完成处理。

**该怎么办**：
- 调小工作尺寸（Settings → 画质与导出 → 工作尺寸，推荐 3072 px 或 2048 px）
- 关闭其他应用释放内存
- 等待设备降温（发热时系统会限制可用内存）

### E-2002：原生堆内存不足
**含义**：C++ 引擎分配内存失败。

**该怎么办**：
- 同 E-2001
- 如果照片尺寸超大（50+ MP），考虑在桌面版处理

### E-2003：GPU 显存不足
**含义**：GPU 显存不足，无法分配渲染缓冲区。

**该怎么办**：
- 调小工作尺寸
- 关闭其他占用 GPU 的应用（游戏、视频播放等）

## E-3xxx：源文件与解码

### E-3001：源文件打开失败
**含义**：无法读取照片文件，可能是文件损坏或存储介质故障。

**该怎么办**：
- 确认文件未损坏（在相册中能正常打开）
- 检查存储空间是否充足
- 尝试将照片复制到其他位置后重新导入

### E-3002：源文件解码失败
**含义**：照片格式不支持或文件损坏。

**该怎么办**：
- 确认照片格式（支持 JPEG、PNG、HEIF、RAW）
- 尝试用其他应用打开验证文件完整性
- 如果是 RAW 文件，确认相机型号在支持列表（docs/DEVICES.md）

### E-3003：不支持的格式
**含义**：照片格式不在支持列表中。

**该怎么办**：
- 查看支持的格式列表（docs/DEVICES.md）
- 使用其他工具转换为 JPEG 或 PNG 后导入

### E-3004：访问被拒绝
**含义**：应用没有读取照片的权限。

**该怎么办**：
- 到系统设置授予存储权限：Settings → Apps → Spektralab-X → Permissions → Storage
- 重新从相册选择照片

## E-4xxx：导出与保存

### E-4001：导出画面异常
**含义**：导出的画面全黑、全白或纯色，通常是参数设置极端或照片本身异常。

**该怎么办**：
- 检查曝光、高光、阴影等参数是否过度
- 尝试重置参数后重新调整
- 如果照片本身就是全黑/全白，这是预期行为

### E-4002：保存失败
**含义**：无法将导出文件保存到相册。

**该怎么办**：
- 检查存储空间是否充足
- 确认应用有写入权限
- 尝试导出为 JPEG（比 TIFF 小）

### E-4003：编码失败
**含义**：JPEG 或 HEIF 编码器失败。

**该怎么办**：
- 尝试切换格式（JPEG ↔ TIFF）
- 调小导出尺寸
- 复制诊断信息反馈

## E-5xxx：系统与权限

### E-5001：系统中断
**含义**：处理时被系统强制中断，通常是内存不足被 lmkd 杀掉。

**该怎么办**：
- 调小工作尺寸
- 关闭其他应用
- 检查系统是否限制了后台运行（Settings → Battery → Autostart）

### E-5002：权限被拒绝
**含义**：缺少必要的系统权限。

**该怎么办**：
- 到系统设置检查权限：Settings → Apps → Spektralab-X → Permissions
- 确保授予了存储、通知等权限

### E-5003：存储空间已满
**含义**：设备存储空间不足，无法保存导出文件。

**该怎么办**：
- 清理设备存储空间
- 删除不需要的文件或应用
- 导出为 JPEG 而非 TIFF（文件更小）

## 反馈问题时

请提供：
1. 错误编码（E-xxxx）
2. 完整错误消息
3. 复制的诊断信息（Settings → 关于与诊断 → 复制诊断信息）
4. 出错时的操作步骤
5. 设备型号和系统版本
