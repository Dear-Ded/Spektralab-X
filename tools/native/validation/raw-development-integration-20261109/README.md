# Android RAW development integration validation

Co-created with GPT (OpenAI), 2026-11-09. This record uses synthetic test names
and source fingerprints only. Private camera files and per-image results remain
outside the public repository.

## Product contract

New RAW imports and legacy records default to neutral linear display. Standard
development is an explicit experimental per-photo choice. Film rendering keeps
the original scene-linear input. A stored choice survives sidecars, processing
jobs and undo, and exposure-group paste only copies it to RAW destinations.

The native output cache is stamped with a render revision. Accepted engine or
no-film changes invalidate the previous frame even when the following render
fails or is cancelled. RAW development and Layer 2 changes alone can repack a
current frame. Kotlin separately checks that pending edits use the same render
input before requesting repack.

## Executed source gates

On AOIDC, against the rebuilt metadata-capable engine and LibRaw:

```sh
bash ./gradlew --no-daemon --max-workers=2 \
  :app:testReleaseUnitTest :app:compileReleaseKotlin \
  :app:externalNativeBuildRelease
```

`android-arm64.log` records the final successful ARM64 native build, Kotlin
compilation and JVM test task. `raw-development-junit.xml` records seven new
tests with no failures, errors or skips. The JVM results were generated by the
preceding build and reused by the final build because only native JNI source
changed. `android-source.sha256` fingerprints the final relevant source inputs.
No APK assembly, release, tag or version task was requested.

The seven JVM tests cover neutral defaults and legacy records, sidecar/job
persistence, explicit reset deltas, selective paste, film-preset isolation,
invalid intent/exposure rejection and output-cache eligibility. These are model
and policy tests, not Android UI/device tests or execution of JNI failure paths.

`nofilm-regression.log` records the actual native app-key parser checks and the
existing no-film regression suite: 120 color/output cases, 780 TIFF row checks,
60 repacks, geometry/crop/turn/flip/resize checks and six invalid requests. The
parser checks verify roundtrip persistence, invalid types and transactional
failure behavior. Separate double-cloud algorithm and packing coverage is in
`../raw-development-20261109/README.md`.

## Remaining acceptance

Native compile success does not exercise JNI render cancellation on an Android
device. Phone runtime, complete UI interactions and visual acceptance remain
unverified. The optional standard curve is not a complete DCP renderer and has
not established camera/Lightroom appearance matching or resolved the separate
film-color complaint. Same-plan strip consistency does not imply identical
preview/export gamut policy or identical tone/downsampling order.
