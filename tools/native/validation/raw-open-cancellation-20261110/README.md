# RAW-open cancellation

Synthetic production-JNI validation, 2026-11-10. The harness includes the actual
JNI translation unit and uses the existing Android bitmap allocation shim.
It does not use private photographs or emulate an Android device.

`jni-normal.log` and `jni-sanitized.log` both pass:

- Original and versioned cancellable RAW entries preserve source float bytes.
- Precise float LinearRaw cancels at 11 deterministic checkpoints, including
  metadata inspection, decode, and after native session creation.
- Integer-compatible and legacy-float fallback each cancel at six checkpoints,
  including progress inside the decoder and after native session creation.
- A separate thread signals the public native token while open is blocked;
  cancellation returns a zero handle with the cancellation classification.
- Cancelled candidates are released; the previous session and repack cache
  survive; a fresh token retries successfully.
- Cancellation while a binned decode budget is active resets that thread-local
  budget before the next full decode.

The runner uses one LibRaw worker for repeatable ordinal checkpoints. Progress
callback counts are scheduling-dependent with multiple workers. The initial
test's cross-execution count assertion failed and is preserved in
`jni-initial-poll-count-failure.log`; it was replaced with checkpoints measured
from the actual JNI call. No production change was needed for that test issue.

ASan/UBSan instrument the JNI translation unit and directly compiled Android
adapter sources. Prebuilt engine/LibRaw/codec archives are not instrumented by
this runner. Leak detection is disabled for the host Vulkan driver; session
counts, candidate ownership and previous-cache contents are explicitly checked.

`source-sha256.txt` identifies the compiled snapshot. Reproduce with
`tools/native/run_jni_raw_cancellation.sh`, setting `UP`, `B`, `CODEC`,
`MATH_DIR`, `VULKAN_HEADERS`, `BUILD_DIR`, `FLOAT_DNG`, `INTEGER_DNG`, and
`LEGACY_FLOAT_DNG`. Fixtures are the synthetic `max2.dng`,
`integer-bayer.dng`, and `fallback-crop.dng` generated by
`raw_precision_input_fixtures.py`. Set `SANITIZE=1 ASAN_OPTIONS=detect_leaks=0`
for the sanitizer run.

`RawOpenCancellationTest` separately checks coroutine ownership and dispatch:
normal completion, immediate signalling while native is blocked, a successful
candidate arriving after cancellation, cancellation before dispatcher entry,
exception/retry token independence, and token-allocation failure.

Cancellation is cooperative. Source-provider descriptor/copy I/O, metadata
`open_file`, individual decoder operations without progress callbacks, source
statistics, resize, thumbnail preparation and synchronous GPU session creation
can finish their current call before the next cancellation check. Cancellation
never frees in-flight native resources. The original `openRaw` ABI remains
available without a cancellation token.
