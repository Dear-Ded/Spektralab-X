## Reproduction

Use the pinned, patched upstream and an existing host build of its engine/IO.
The host fixture runners are:

```sh
UP="$patched_upstream" BUILD_DIR="$scratch/f16" bash tools/native/run_bitmap_f16.sh
UP="$patched_upstream" B="$host_build" BUILD_DIR="$scratch/float" bash tools/native/run_float_dng_linear.sh
UP="$patched_upstream" B="$host_build" BUILD_DIR="$scratch/dispatch" bash tools/native/run_raw_precision_input.sh
# Add SANITIZE=1 for the sanitizer variants; no production decoder option is changed.
```

For the production JNI runner, additionally set CODEC to the libjpeg-turbo
install, VULKAN_HEADERS to its include directory, MATH_DIR to the directory
containing upstream_input_math.inc and upstream_output_math.inc generated by
the Android CMake extraction, and FLOAT_DNG to the generated
`dispatch/fixtures/nonunit-green-neutral.dng`. Then run
`UP="$patched_upstream" B="$host_build" BUILD_DIR="$scratch/jni" bash tools/native/run_jni_precision.sh`.
The harness uses no user camera file and no device graphics shim is treated as
physical-device acceptance.

The Android test invocation selected PhotoInputColorTest, PhotoInputF16Test,
SourceGamutRoutingTest, FilmThumbnailColorTest, ProcessingQueueGrantTest,
PhotoGeometryTest and OutputColorTagTest, plus `:app:testReleaseUnitTest` and
`:app:compileReleaseKotlin`. The final native invocation used
`SPK_UPSTREAM="$clean_patched_upstream" spk-build "$repo" :app:externalNativeBuildRelease`.
Neither invocation includes APK assembly.
