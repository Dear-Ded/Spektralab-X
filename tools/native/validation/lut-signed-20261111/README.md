# Signed-domain diagnostic evidence

GPT (OpenAI), 2026-11-11. All inputs are synthetic. No private image, APK,
version or production shader change. Interpretation and complete reproduction:
[signed-domain report](../../../../docs/LUT_SIGNED_DOMAIN_2026-11-11.md).

`aoidc/` and `ibx/` retain the unchanged 49-overlay reference runs. Each has the
actual local sample/reference/LUT outputs, GPU coordinates, full aggregate
report, contracts, source hashes and logs. Both reports verify the earlier
33^3 held-out rows and float32 lattice exactly. AOIDC also retains the complete
old-gate CSV/lattice byte-comparison result after rerunning `MODE=gate`.

`counterfactual/{aoidc,ibx}/` retain the isolated single-expression intervention,
compiler control, immutable-input manifest and comparison. Its reference is
deliberately different; do not mix these errors with the unchanged gate or use
them as a production fix. The portable checker needs `--counterfactual` there.
The shader compiler control matched the original SPIR-V before the changed
shader ran. The `run-inputs.sha256` and `experiment.json` identify each actual
binary/shader and original protected inputs; machine paths in them are run
identities, not portable reproduction defaults.

Full global samples/grids and positive-cell reconstructed byte arrays are
regenerated by the experiment scripts rather than committed. Compact records
are not sufficient to independently replay all global errors or immutable-file
checks. They do independently retain all local inputs and recorded outputs.
The two hosts may differ in some low output bits, so compare within each host.

Recheck the retained local records from the repository root, without a GPU:

```bash
python3 -B tools/lut_experiment/check_signed_evidence.py \
  tools/native/validation/lut-signed-20261111/aoidc \
  tools/native/validation/lut-signed-20261111/ibx --self-test
python3 -B tools/lut_experiment/check_signed_evidence.py \
  tools/native/validation/lut-signed-20261111/counterfactual/aoidc \
  tools/native/validation/lut-signed-20261111/counterfactual/ibx \
  --counterfactual --self-test
```

The checker validates exact float32 sample/coordinate identity, finite bounded
P3 outputs, GPU coordinates, all local DE00 summaries, all 65 consecutive green
values and recorded maximum adjacent reference change. Its six corruption
controls must all be rejected, including when Python assertions are disabled.
`compact-check.jsonl` files retain the actual local verification results.

The independent DE00 reference checks 34 author-supplied pairs. Neither portable
replay nor CPU Vulkan runs establish Android GPU correctness, physical fidelity,
natural-photo coverage, a support-domain certificate or memory/performance on
a phone. The engine/upstream pin and RAW linear default remain unchanged.
