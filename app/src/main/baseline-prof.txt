# Baseline Profile, written by hand (docs: developer.android.com/topic/performance/baselineprofiles/manually-create-measure).
# AGP compiles it into the release APK (assets/dexopt/baseline.prof) and profileinstaller
# hands it to ART on first launch, so these paths run AOT-compiled from the first start
# instead of interpreted until the cloud profile arrives (sideloaded builds never get one).
#
# Not generated in CI: a Macrobenchmark run needs an arm64 device or emulator with
# Vulkan, and GitHub's x86_64 runners can load neither libspektralab_jni.so (arm64-v8a
# only) nor a Vulkan driver. Compose, activity and lifecycle ship their own profiles;
# these lines cover this app's code. Update when a hot path moves to a new class.
