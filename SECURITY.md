# 安全策略 / Security Policy

只维护最新的 pre-release。/ Only the latest pre-release is supported.

发现安全问题请**不要**公开提 issue，在本仓库的 **Security → Report a vulnerability** 里私下报告。这是个人维护的项目，一般两周内回复。

Please do **not** open a public issue. Report privately via **Security → Report a vulnerability**. Expect a reply within about two weeks (single maintainer).

应用不申请网络权限，不收集任何数据；导出的 JPEG 不写入位置信息。
The app requests no network permission and collects no data; exported JPEGs carry no location.
